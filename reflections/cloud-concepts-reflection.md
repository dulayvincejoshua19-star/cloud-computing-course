# Cloud Computing Concepts Reflection

Cloud computing has become an essential part of my daily life, even before I fully understood the technology behind it. Many of the applications I use every day rely on cloud services that make storing data, communicating, and accessing information more convenient.

One cloud service I frequently use is **Google Drive**. It follows the **Software as a Service (SaaS)** model because users can access file storage and productivity tools through a web browser without installing or managing the underlying infrastructure. It uses the **Public Cloud** deployment model since the service is available to anyone with a Google account over the internet.

Another application I regularly use is **Facebook Messenger**. It is also an example of **SaaS** because Meta manages the servers, software, and updates while users simply access the messaging platform online. Messenger operates on the **Public Cloud** because millions of users worldwide access the same cloud infrastructure securely through the internet.

I also use **Canva** for creating presentations and graphic designs. Canva is classified as **SaaS** because it provides design tools directly through the cloud without requiring users to install complex software. Like Google Drive and Messenger, Canva uses the **Public Cloud** deployment model since it serves users globally through internet-based cloud services.

Version control is equally important when working on cloud computing projects. Cloud systems often involve configuration files, scripts, and application code that multiple developers edit simultaneously. Without version control, files can easily be overwritten or important changes may be lost. Git helps record every modification, allowing developers to review history, restore previous versions, and manage different branches of development.

GitHub further improves collaboration by providing a centralized repository where team members can share code, review changes through pull requests, report issues, and resolve conflicts before deployment. These features help reduce errors, improve teamwork, and maintain reliable cloud applications. Learning Git and GitHub alongside cloud computing prepares me for professional software development because they are essential tools used in modern cloud-based projects.
